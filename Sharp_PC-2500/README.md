# Sharp PC-2500
The Sharp PC-2500 was a development of the Sharp PC-1350.  There were two models:<br>
- PC-2500 (export version)
- PC-2500S (domestic Japanese version)

It's an A4 format Portable Computer ... or Electronic Calculator depending on which side of the case you look at ... that runs S-BASIC and has built-in business applications.  <br>

Its 150x32 pixel LCD is capable of 24x4 characters.<br>

It uses an Hitachi SC61860 8-bit CPU with an internal 8KB ROM (code A14) for BIOS.  The S-BASIC and business applications are provided on an additional two 32KB ROMs giving 72KB of ROM in total.<br>

The other main chips are:
- SC61J216F (gate array)
- DLG3001E (PCU, printer control unit)
- SC43537 (DISP1 to DISP5)
- SC613256 (ROM1 & ROM2)
- HM6116LFP (RAM5 & RAM6)

The ROM1 code is FS43 for both models - this is S-BASIC.<br>
The ROM2 code is FS44 for Japan domestic and FS45 for export - this is for the business applications.<br>

It's quoted as having 5KB of RAM built-in but this seems inflated seeing as it only has a pair of 2KB RAM chips ... perhaps they are including the screen RAM?  The RAM can be expanded with either an 8KB or 16KB battery-backed RAM card.<br>

It includes a four pen/colour plotter/printer and has cassette and serial I/O ports.<br>
