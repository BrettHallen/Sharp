# MZ-80B Motherboard Modifications
I have two motherboards - one has some bodge wiring that I suspect is a later manufacture.  There is nothing I can see to indicate a revision to the actual PCB itself.<br>

- IC36 pin 7 to IC36 pin 10
- 330pF (331) ceramic capacitor between IC46 pins 1 & 2 and C69 GND
- IC46 pins 1 & 2 to IC32 pin 3
- IC32 pin 2 to IC39 pin 2
- IC46 pin 3 to IC35 pins 1 & 2
- IC15 pin 8 to IC2 pin 14 (ground wire)
- CN13 pin 2 to IC2 pin 15 (ground wire)
